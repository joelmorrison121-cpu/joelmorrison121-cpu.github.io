PLAYABLE DESKTOP BUILD / v2.1 RELEASED

Crash Course.

Training on the hardest track produced the only driver that laps all four.

A 2D racing game in which neural-network drivers (11 inputs → 8 → 3) learn to race by neuroevolution: selection and mutation across generations, with no hand-written driving rules. Every result is repeated across random seeds and tested on tracks the drivers never trained on.

  • Python
  • Pygame
  • Neuroevolution
  • unittest

My contribution: solo project. I designed and built the car physics, track and checkpoints, sensors, neural network and evolutionary trainer, using AI assistance for explanations and debugging.

GitHub repository ↗Read the build notes ↗
What works & what I learned +

Works: four tracks, including curved ones built from a centre-line path, plus checkpoints at any angle, a lap-time reward, save/resume, live progress graphs, a start menu and a race-the-champion mode. All 3 technical-track seeds learned a lap (first at generation 28 ± 9), and one of them laps all four tracks. Drivers trained on the flowing track never managed the hairpins (0/5). 25 unit tests pass.

Didn't work yet: a look-ahead input meant to help on hairpins was inconclusive over 3 seeds, so it stays optional until I've run more.

Learned: fixed-timestep simulation, ray-cast sensors and fitness design. I also learned to inspect a network's inputs and outputs before assuming the physics is broken. One early AI pressed the accelerator and the brake at the same time.

Desktop app (Python 3.10+, pygame-ce). The README covers setup, controls and training. Download the v2.1 source ZIP ↓
